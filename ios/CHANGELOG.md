# iOS App 更新日志

本文件只记录 TelePilot iOS App 自身的变化，遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与 [SemVer](https://semver.org/lang/zh-CN/)。iOS App 版本号独立于 TelePilot 服务器版本，规则见仓库根目录 `AGENTS.md`「iOS 版本」。

- **MINOR（0.X.0）**：用户可感知的新能力、页面或信息架构重组、重要工作流变化。
- **PATCH（0.X.Y）**：bug 修复、文案、小 UI 与兼容性调整。
- 版本号只在 iOS 发版检查点 bump；开发中的改动先记入 `Unreleased`。build 号由 CI 打包时生成，不写在这里。
- 每个版本段落的标题格式为 `## [版本] - 日期 · 级别 · 主题`，下一行用 `> 对应服务器：…` 注明随哪个服务器检查点或 Beta 合并发布。本文件随 App 打包，在“关于 → App 更新日志”中离线显示，请保持该格式。

## [0.13.1] - 2026-10-27 · patch（补丁版本） · 体验优化第六轮：搜索移到左上角、菜单收回动画、助手打开卡顿、消息操作

> 对应服务器：随 Beta 合并发布（仅 iOS 改动，服务器版本不变，仍为 0.106.0-beta.9）

### 改进

- 页面级搜索统一为导航栏左上角的放大镜按钮：插件（插件中心／发现／已安装）、AI（概览／供应商／用量）、更多、概览，以及账号、日志列表、全部流水、管理记录列表、助手会话列表，点按后展开系统搜索栏并可直接输入，作用于当前页面或当前分页；点“取消”收起并清空。分段控件下方不再常驻搜索框，“更多”的全局搜索不再弹出单独页面。
- 助手消息操作放到对应消息下方：自己发的消息下有「复制消息」「编辑消息」（编辑后重新生成最新一轮），助手回答下有「复制回复」（复制正文 Markdown，不含本轮详情与工具卡片）「重新生成」（需确认）；复制后图标短暂变为对勾并有轻触反馈。正在生成的回答不显示这些按钮。
- 打开长会话更快：导航栏与输入栏立即可用，先显示最近一屏消息，更早的消息随后增量补上；加载过程中即可上翻，不再被拉回底部。

### 修复

- 插件「发现」「已安装」与 AI「供应商」「用量」页顶部的分段控件与搜索框左右两端被分组卡片圆角裁切；现在所有分页的分段控件位置、尺寸、圆角完全一致。
- 助手输入栏的模型选择菜单与「+」附件菜单收回时约一秒的闪烁、错位：菜单标签改为固定尺寸，输入栏玻璃改画在背景层，选择模型不再触发整个输入栏重排。

## [0.13.0] - 2026-10-27 · minor（次版本） · 体验优化第五轮：原生分段与筛选、玻璃输入栏、一键体检

> 对应服务器：0.106.0-beta.9

### 新增

- 概览导航栏右上角新增「一键体检」（听诊器图标）：点按打开体检面板，直接调用服务器的只读体检（与对助手说“体检一下”同一套检查，约 25 秒内查完基础设施、版本、总闸、账号与 Worker、错误日志、模型供应商、系统助手、定时任务、插件、通知与推送 10 项），显示总体结论、每项状态、原因与修复建议，并可一键前往对应页面处理；不会修改任何配置。

### 改进

- 助手输入栏改版为原生 Liquid Glass 圆角输入栏：上方多行输入框，下方一行工具栏——左下「+」添加图片（照片或文件），右下发送按钮（任务执行中且输入为空时变为停止），发送按钮左侧是本轮模型选择（显示模型短名）；去掉输入框上方的模型胶囊。输入栏贴底部安全区并随键盘上移。
- 回答底部的「本轮详情」改为两行：第一行供应商与模型名，第二行输入 / 输出词元、工具调用次数与耗时；点开仍显示完整详情。
- 全 App 分段切换统一：插件中心／发现／已安装、AI 概览／供应商／用量、插件详情各分区与待确认操作都用同一款系统分段控件，统一放在导航标题正下方、内容顶部，左右与下方卡片对齐；有搜索的页面搜索栏紧贴其下，改用系统原生搜索框。
- 插件中心的状态筛选（全部／运行中／需处理／可更新／收藏）与分类合并为一个原生筛选菜单，“选择配置的账号”改为原生选择器；多模型对话测试的模型多选改为系统开关。

### 移除

- 概览的「需要处理」区块（判断不准且给不出解决方法）连同“自定义概览”里的对应开关；顶部一句话只陈述能确认的服务器状态，全面判断交给「一键体检」。

## [0.11.0] - 2026-10-26 · minor（次版本） · Cloudflare Access：App 内 Google 验证

> 对应服务器：0.106.0-beta.6

### 新增

- 支持服务器前套了 Cloudflare Tunnel + Access（Allow 策略 = 邮箱白名单 + Google 登录）的部署，**Cloudflare 后台无需任何修改**：登录页「Cloudflare Access（可选）」区和 设置 → Cloudflare Access 新增「使用 Google 验证」。App 照搬官方 `cloudflared access login` 流程：用系统登录窗（Google 不允许 App 内嵌网页登录）打开服务器的 Access 登录页，同时轮询 Cloudflare 令牌转交服务，取回用本机一次性密钥加密的 Access 登录令牌后自动关闭窗口。
- 令牌只保存在本机钥匙串、按服务器分别保存、不同步 iCloud、不写日志；之后 App 的所有请求（登录、读取、写操作、下载上传、助手实时输出、推送注册等）都带 `cf-access-token` 请求头。界面显示 Access 会话的账号邮箱与到期时间，可随时「移除 Access 登录」。
- 「高级：Service Token」保留为可选项（需要在 Access 应用里另加一条 Action 为 Service Auth 的策略）；填写后只带 `CF-Access-Client-Id` / `CF-Access-Client-Secret`，清除后自动改回 Google 验证。
- App 内「Cloudflare Access 使用说明」：Google 验证步骤、到期处理、Binding Cookie 注意事项与 Service Token 后台配置。

### 改进

- 被 Cloudflare Access 拦截时不再笼统显示「服务器返回了重定向」：按情况提示「请先用 Google 完成 Access 验证」「Access 登录已过期」「Access 不再接受当前的登录」或「Service Token 被拒绝」。登录页在 Access 区显示引导；已登录时（会话过期或请求被 302 到 `*.cloudflareaccess.com`）直接弹出 Access 页面，一键重新验证，验证后自动关闭并刷新数据。
- Access 拦截发生在 Cloudflare 边缘，不会被当成登录失效而清除 TelePilot 会话；写操作被拦截时明确是「未执行」，重新验证后不会自动重新提交。其他重定向仍按原安全规则拒绝。
- 启动时恢复会话被 Access 拦截：在登录页完成 Google 验证后自动用原会话只读重试，无需重新输入密码。
- 「更换服务器」会一并移除这台服务器的 Access 登录令牌与 Service Token。

## [0.10.0] - 2026-10-26 · minor（次版本） · 插件页参考 App Store 重做

> 对应服务器：0.106.0-beta.4

### 新增

- 插件页改为「插件中心 / 发现 / 已安装」三段：「已安装」参考 App Store 的更新页，最上方是「待更新」（带数量与「全部更新」），每张卡片显示版本 x → y、发布时间和可展开的「新功能」，可单独更新；下面是「最近已更新」和全部已安装插件。插件 Tab 显示可更新数量角标。
- 「发现」按分类列出插件仓库和本地参考插件里的插件，支持搜索；未安装的显示「获取」（安装前确认），已安装的显示「打开」，有新版本的显示「更新」。仓库管理、从 Git 地址或文件安装放在列表底部。
- 新的插件产品页：大图标、名称、作者和主按钮（获取 / 更新 / 打开），横向信息条显示版本、权限数量、最低 TelePilot 版本、来源与签名、启用账号数；随后是「新功能」与版本历史、简介、权限、配置与管理入口；服务器停用与卸载放在底部，确认框挂在各自按钮上。
- 插件列表使用 App Store 式的圆角图标：插件没有自带图标时，用名称首字（或分类符号）生成，颜色固定对应插件。

### 改进

- 「全部更新」逐个执行并逐项显示真实结果：某项失败不影响其他项；网络中断导致结果未知时停止后续更新，重新读取状态并提示核对。安装、更新、检查更新都不会自动重试。
- 读取插件仓库与检查更新改用长超时，首次读取仓库（服务器需要下载）不再提前报超时。
- 旧服务器缺少更新日志、作者等字段时，对应区域直接隐藏，不影响其他功能。

## [0.9.0] - 2026-10-26 · minor（次版本） · Skills 管理与插件 skill 多选

> 对应服务器：0.106.0-beta.1

### 新增

- 新增 Skills 管理（助手菜单 → Skills，或 AI → 配置 → Skills）：查看已安装、插件内置与 TelePilot 内置的 skill，分别开关“对系统 Agent 启用”“对插件启用”；查看 SKILL.md 与附属文件，编辑可编辑的 skill。
- 安装 skill：支持 GitHub 链接（可填分支/标签与子目录）、zip 链接、粘贴 SKILL.md，以及从“文件”选择 .zip 或 .md；安装结果列出跳过的文件，常见失败原因以中文说明。
- 插件内置 skill：编辑后保存为你的版本；插件升级带来新默认内容时标出“内置有新版本”，可查看与默认版本的差异、恢复默认或保留我的修改。卸载、恢复默认等操作在触发按钮上确认，网络中断时如实提示“结果待确认”，不会自动重试。
- 插件配置支持“Skills 多选”字段（例如 AI 答疑插件的“使用已安装的 Agent Skills”）：从对插件启用的 skill 中勾选，已停用或卸载的已选项会标出“当前不可用”。

### 变更

- 插件配置的模型选择改为统一模型列表（与 Web 一致）：所有 Provider 下已启用的文本模型按 Provider 分组列出，选中模型后自动填写对应的 Provider；Provider 选择器保留，并标注“随模型自动填写”。
- 插件配置表单：只有真正必填的项才标「必填」，写着“可选”或有默认值的项不再显示「必填」；字段按插件声明的顺序与分组（如“触发方式”“AI 模型”“消息模板”）排列，与 Web 一致，不再按标题字母排序。
- 插件配置里对象、列表项的可选字段只显示一个输入控件，不再多出“是否提交此项”开关；留空时使用插件默认值。
- 较长的插件配置页拆成子页面：主页只留基础设置与模型等常用项，其他分组（如触发方式、PT 站点数据源、消息模板）各成一行，显示是否启用、已配置几项，有必填项未填时显示红点；在子页面里改的内容回到主页统一检查保存，有未保存的修改时返回会先确认是否放弃。
