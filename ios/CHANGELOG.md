# iOS App 更新日志

本文件只记录 TelePilot iOS App 自身的变化，遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与 [SemVer](https://semver.org/lang/zh-CN/)。iOS App 版本号独立于 TelePilot 服务器版本，规则见仓库根目录 `AGENTS.md`「iOS 版本」。

- **MINOR（0.X.0）**：用户可感知的新能力、页面或信息架构重组、重要工作流变化。
- **PATCH（0.X.Y）**：bug 修复、文案、小 UI 与兼容性调整。
- 版本号只在 iOS 发版检查点 bump；开发中的改动先记入 `Unreleased`。build 号由 CI 打包时生成，不写在这里。
- 每个版本段落的标题格式为 `## [版本] - 日期 · 级别 · 主题`，下一行用 `> 对应服务器：…` 注明随哪个服务器检查点或 Beta 合并发布。本文件随 App 打包，在“关于 → App 更新日志”中离线显示，请保持该格式。

## [Unreleased]

## [0.9.0] - 2026-10-26 · minor（次版本） · Skills 管理与插件 skill 多选

> 对应服务器：Beta 0.105.0-beta.1 之后（PR #62，下一个服务器检查点待定）

### 新增

- 新增 Skills 管理（助手菜单 → Skills，或 AI → 配置 → Skills）：查看已安装、插件内置与 TelePilot 内置的 skill，分别开关“对系统 Agent 启用”“对插件启用”；查看 SKILL.md 与附属文件，编辑可编辑的 skill。
- 安装 skill：支持 GitHub 链接（可填分支/标签与子目录）、zip 链接、粘贴 SKILL.md，以及从“文件”选择 .zip 或 .md；安装结果列出跳过的文件，常见失败原因以中文说明。
- 插件内置 skill：编辑后保存为你的版本；插件升级带来新默认内容时标出“内置有新版本”，可查看与默认版本的差异、恢复默认或保留我的修改。卸载、恢复默认等操作在触发按钮上确认，网络中断时如实提示“结果待确认”，不会自动重试。
- 插件配置支持“Skills 多选”字段（例如 AI 答疑插件的“使用已安装的 Agent Skills”）：从对插件启用的 skill 中勾选，已停用或卸载的已选项会标出“当前不可用”。

### 变更

- 插件配置的模型选择改为统一模型列表（与 Web 一致）：所有 Provider 下已启用的文本模型按 Provider 分组列出，选中模型后自动填写对应的 Provider；Provider 选择器保留，并标注“随模型自动填写”。
- 插件配置表单：只有真正必填的项才标「必填」，写着“可选”或有默认值的项不再显示「必填」；字段按插件声明的顺序与分组（如“触发方式”“AI 模型”“消息模板”）排列，与 Web 一致，不再按标题字母排序。
- 插件配置里对象、列表项的可选字段只显示一个输入控件，不再多出“是否提交此项”开关；留空时使用插件默认值。
- 较长的插件配置页拆成子页面：主页只留基础设置与模型等常用项，其他分组（如触发方式、PT 站点数据源、消息模板）各成一行，显示是否启用、已配置几项，有必填项未填时显示红点；在子页面里改的内容回到主页统一检查保存，有未保存的修改时返回会先确认是否放弃。

## [0.8.0] - 2026-10-25 · minor（次版本） · App 内更新日志与规范版本号

> 对应服务器：Beta 0.105.0-beta.1 之后（PR #59，下一个服务器检查点待定）

### 新增

- “关于”页新增“App 更新日志”：按版本列出 iOS App 自身的变化，内容随 App 打包，离线可看，不依赖服务器；当前安装的版本会被标出。

## [0.7.0] - 2026-10-25 · minor（次版本） · 插件安装表单修复与 Provider／模型选择器

> 对应服务器：Beta 0.105.0-beta.1 之后（PR #58）

### 新增

- 插件配置表单支持原生 Provider／模型选择器：可直接从 TelePilot AI Provider（含“自动路由”）和所选 Provider 已启用的模型中选择，其他动态选项从指定字段读取候选；不在候选中的旧值以“当前值：…”保留。ai-chat、ai_redpacket、quick_qa、sum、interaction-ai-chat 等插件的 Provider／模型字段由此可直接选择。

### 修复

- 从插件仓库“安装此插件”时，“安装后默认启用”“替换已有插件”不再各出现两个同名开关，提交值即所见值，并补充“安装后默认启用”的含义说明。
- 插件实际已安装、界面却报“服务器拒绝了请求（HTTP 409）”：安装、刷新与批量更新改用长超时，插件已存在、目录冲突等错误改为中文说明。
- 插件全局停用时，账号详情不再显示“运行异常”和误导性的“已提交启用”，改为“全局已停用”“已开启 · 未生效”，并提供直达“全局启用插件”的按钮。

## [0.6.1] - 2026-10-25 · patch（补丁版本） · 确认框位置与顶栏抖动修复

> 对应服务器：Beta 0.105.0-beta.1 之后（PR #56）

### 修复

- 二次确认框改为从触发它的按钮或行弹出，不再出现在屏幕中上部、箭头指向列表中部；多个操作共用确认时各自独立弹出。
- 插件页与 AI 页滑到顶部后顶栏不再持续抖动：顶部分段切换改为随内容滚动，并使用系统默认尺寸。

## [0.6.0] - 2026-10-25 · minor（次版本） · 第三轮体验改进、巡检与推送状态

> 对应服务器：Beta 0.105.0-beta.1 之后（PR #53 第三轮集成）

### 新增

- AI 管理新增“全部供应商巡检”：可搜索、按供应商或单个模型挑选范围，开始前由服务器核对并确认，显示真实进度与按供应商分组的结果；单个供应商的测活改为“供应商测活”。
- “添加供应商”改为与 Web 对齐的原生表单：常用项只保留名称、接入地址、API Key、接口协议与模型，其余收进“高级设置”并逐项中文说明。
- 设置 → Apple 推送通知新增“推送状态”检查清单（通知权限、设备注册、服务器 APNs 配置、推送环境与 Bundle ID 是否匹配），新增 App 内“配置教程”；测试通知结果区分“Apple 已接受 / 未送出 / 结果未知”，通知类别可按设备开关。
- 账号管理显示 Bot 的“访客模式（Guest Mode）：已开启／未开启”及 BotFather 开启方法。
- 服务器更新面板新增“更新通道”：显示并可切换检查与拉取更新的分支（切换前需确认）；“自动检查更新”的开关与频率改为面板内的原生控件。
- 设置新增“外观”：自动（跟随系统）／浅色／深色。
- “更多”页顶部新增红色高亮的“全局紧急停止”，显示真实状态，启用或解除前需确认。

### 变更

- 概览顶部改为品牌头与“当前服务器”卡片（地址、连接状态、服务器版本与通道、登录用户），刷新改为并发读取并保留上次“需要处理”结果。
- 插件页与 AI 页的分段切换、插件中心的状态筛选改为 iOS 26 原生 Liquid Glass 样式；“查看范围”改名为“选择配置的账号：”。
- 统一导航标题：四个一级 Tab 使用大标题，二级页面、详情与弹窗使用行内标题。
- 更新入口收敛为“关于与更新”页里唯一的“检查服务器更新”，“关于与更新”入口移到“更多”和“设置”的最底部。
- 助手回答底部改为与 Web 一致的一行摘要（模型 · 词元 · 工具次数 · 耗时），点按展开详情。
- AI 概览移除重复的“管理供应商与模型”入口，“供应商”分栏在供应商较多时提供搜索。

## [0.5.0] - 2026-10-25 · minor（次版本） · 第二轮体验重做与诊断

> 对应服务器：0.105.0-beta.1

### 新增

- 助手：会话可左滑或长按删除；输入框重做，最多 8 行自动增高，独立发送与停止按钮；Agent 页改为可拖动的玻璃“最小化”悬浮按钮；回答支持代码块、列表、表格等 Markdown。
- AI：模型测活对齐 Web；新增原生“AI 全局设置”“AI 指令与账号启用”页与“AI 术语说明”页，术语全面中文化。
- 概览新增“需要处理”“关键数字”“快捷操作”区块，可在自定义概览中开关。
- 资金台账新增汇总卡片、趋势与分布图表、筛选和可读流水详情。
- 日志与诊断重做：统一日志列表、消息处理四步详情、调用链时间线和脱敏的“复制诊断信息”。
- 新增“关于”页（App 版本与构建号、服务器版本与地址、仓库与许可），服务器“检查更新”独立为按钮与面板，应用更新需确认且不自动重试。
- 界面锁新增“需要验证”宽限期（立即／1／5／15 分钟）。

### 变更

- 插件中心卡片改为紧凑布局；配置改为一步进入编辑并在保存前对比“原值 → 新值”；技术信息改为分组可读视图，“维护”更名为“安装维护”。
- 统一列表入口图标。

### 修复

- 登录时修改用户名不再清空密码，服务器地址可省略 `https://`。
- 推送等入口直接切换到 Agent 标签页打开对应会话，不再弹出第二个助手；流式回复停留底部时自动跟随滚动。
- 账号暂停／恢复后的同步期间显示“正在同步”，不再误报“服务状态已过期”。
- 插件全局配置读取完整，从“账号配置”子页面返回不再跳回“概况”；测活进度、日志统计、资金台账筛选与服务器更新提交收据在切换页面或重启后保持正确。

## [0.4.0] - 2026-10-25 · minor（次版本） · 首个原生客户端与 APNs

> 对应服务器：0.104.0-beta.1

### 新增

- 首个 iOS 原生客户端：复用服务器 Cookie 与 CSRF 登录，提供健康概览、账号列表与详情、暂停与恢复，并可在浏览器打开完整管理台。
- 完整管理能力：账号自动化、插件与规则、指令任务、AI 与系统助手、日志诊断、资金台账、Webhook、系统维护等原生入口；Face ID 解锁、隐私遮盖、全局搜索、收藏、可定制首页、iPad 双栏布局和原生文件导入导出。
- 可选 APNs 推送：助手待确认、任务完成和运行异常通知，通知不携带认证凭据或业务敏感正文。
- 原生 Liquid Glass 底栏，固定为“概览、插件、AI、更多”，iOS 27 上使用原生圆形 Agent 入口；插件与 AI 工作流按账号与用途分段。
